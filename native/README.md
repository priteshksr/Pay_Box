# PayBox — Capacitor shell

This folder wraps the PayBox PWA in a Capacitor 6 native shell so we can
ship it to the iOS App Store and Google Play.

The web code is the single source of truth — it lives at
[../index.html](../index.html). This folder just bundles and signs it.

## Quick start

```bash
# From the My_Box/native/ folder:
npm install                # installs Capacitor + plugins
npm run add:android        # scaffolds android/ and runs sync
npm run add:ios            # scaffolds ios/ and runs sync (macOS only)

# After every web change:
npm run sync               # copy web assets + cap sync both platforms

# Opening native IDEs:
npm run open:android       # Android Studio
npm run open:ios           # Xcode
```

See [../NATIVE.md](../NATIVE.md) for the full build / sign / upload
runbook.

## Folder layout

```
native/
  capacitor.config.ts   # app id, name, plugin config
  package.json          # Capacitor + plugin dependencies
  scripts/sync-web.js   # copies web assets into www/ before cap sync
  www/                  # generated — do NOT edit by hand
  android/              # generated by `npm run add:android`
  ios/                  # generated by `npm run add:ios`
  resources/            # optional PNGs for @capacitor/assets
```
